# WisdomLink2 需求文档（正式版 v1.2）

> 基于代码实际状态反向整理，描述系统当前已交付的业务能力。
>
> 修订记录：v1.1 → v1.2（2026-09-17）：§3.9 Wiki 补充页面树文件夹分组、页面编辑/上下线/删除全生命周期、树内文件夹管理、悬停/右键操作入口、宽屏内联+窄屏 Drawer 响应式。

## 1. 产品定位

WisdomLink2 是一个企业级智能知识库平台：将企业的文档、Wiki、QA、知识图谱统一沉淀，提供基于 RAG 的可信问答（答案必带引用、可四级溯源到原始文件）、高频问题秒回（QA 快速命中）、知识关联检索（图谱多跳）。

## 2. 用户角色

| 角色 | 主要任务 | 认证方式 |
|---|---|---|
| 普通用户 | 提问、查看引用/溯源、浏览 Wiki、反馈 | 免登录（可信内网） |
| 管理员 | 文档上传/清洗规则/QA 维护/图谱抽取确认/Token 用量查看/运行时配置 | JWT（内置账号） |
| 第三方系统 | API 检索/问答 | V2（API Key） |

## 3. 功能需求（已实现）

### 3.1 知识库与文件夹
- 创建/归档知识库（唯一权限与运营单元，V2 以库维度授权）
- 库内多级文件夹分类（上限 5 级），文件夹不参与权限
- 检索范围可选定知识库或细化到文件夹

### 3.2 文档管理
- 上传 PDF/Word(docx)/Excel/PPT(**.pptx)/Markdown/TXT/HTML/图片（自动 OCR），单文件 ≤100MB
- SHA-256 内容判重（同库重复拒绝 409，可选新建版本）
- 状态机：已上传→解析中→清洗中→索引中→已发布 / 失败（瞬态/永久分类）
- 批量重处理（按文档列表或知识库范围）
- generation 原子发布：新分片 `active=false` 暂存→向量化→原子切换→旧代下线（重建期间检索不中断）
- 软删除（回收站 30 天，启动时+每小时巡检自动物理清理，级联清理向量与原件）

### 3.3 OCR（图片文字提取）
- 四模式配置切换：`none / local / api / auto`
- local：Tesseract（Docker 镜像内置，Windows 需另装）
- api：LLM 视觉模型（智谱 GLM-4V-flash **免费**，中文识别 95%+，Key 自动回退继承 Embedding Key）
- auto：local 先试→失败自动切 api（推荐默认）
- 识别结果保留原始排版（标题/段落/表格），入索引可被检索

### 3.3 数据清洗
- 规则链：页眉页脚/水印/重复段落/格式规范化/OCR 噪声/敏感信息脱敏
- 白名单动作（remove/normalize/mark），不改语义，逐条留痕（clean_log）
- 清洗前后 diff 对照视图，按原文一键重建索引

### 3.4 分片与索引
- 父子分片：child 512 token 入向量库，parent 2048 供生成上下文
- 语义分片器：原子块保护（表格/代码不内切）、句子边界切点、结构块 1.5× 上限二次切分
- 分片类型标签（text/table/code），入 chunk_meta.chunk_type
- 仅 child 块向量化；parent 经 MySQL 按 seq 回捞

### 3.5 检索
- 三路召回：稠密向量（ANN/HNSW）+ BM25（jieba 分词）+ 图谱关联（实体链接→多跳扩展→证据回捞）
- RRF 融合（k=60），重排后相关性下限过滤（低相关内容不进入引用）
- 本地 ONNX Reranker 精排（bge-reranker，sigmoid 归一，启动预热+加载锁）
- 相邻分片补充：命中 chunk N 自动补 N±1 上下文
- 运行时可调：Top-K / 重排保留数 / 相关性下限（即时生效，不用重启）

### 3.6 QA 快速命中
- QA 对管理：标准问/答案/相似问变体/权重/启停/命中统计
- 两级命中：归一化精确匹配（O(1) 字典）→ 向量相似双阈值（0.92+分差 0.02）
- 优先级：QA → RAG（两级命中；语义缓存未实现，延后至 V2）；QA 命中 0 生成 token（节省量记账）
- 变更后字典/向量双写，1 分钟内生效
- 待沉淀榜单：问答日志高频/未命中问题一键转 QA

### 3.7 问答
- SSE 真流式：检索完成即转发首个 token（不等整段生成）
- 多轮对话（最近 4 轮上下文注入，指代消解）
- 引用编号 [n] 可点击，打开四级溯源抽屉
- 拒答（知识库无依据时明确说明）+ 冲突提示（双引用+以最新生效文档为准）
- 建议问题（LLM 生成 3 个追问）（V1 未实现，延后）
- 取消流（路由离开/组件卸载即中止 SSE，释放资源）
- 重生成失败自动恢复旧消息

### 3.8 多级溯源
- 四级链路：引用编号 → 知识片段（含清洗前后 diff）→ 文档版本与位置 → 原始文件在线预览
- 片段指纹实时校验（SHA-256 比对，篡改即警示并禁止作为依据）
- 原件在线预览：PDF 内嵌渲染 / Markdown 排版渲染 / 图片直显 / **Word-Excel-PPT 入库时自动转 Markdown（含嵌入图片提取）**——全类型零外部依赖（不需要 LibreOffice）

### 3.9 Wiki
- Markdown 编辑器 + 页面树（复用知识库文件夹结构分组，页面按归属文件夹挂树；正文点击后懒加载）
- 页面全生命周期操作：新建 / 编辑（原地新版本）/ 上下线（下线即时退出检索，可随时恢复）/ 删除（回收站 30 天）
- 操作入口：内容区操作栏 + 树节点悬停快捷图标 + 右键菜单（编辑/上下线/删除/建子文件夹/建页面）
- 文件夹管理：页面树内可新建文件夹/子文件夹、删除文件夹（其下页面回落上级或根目录）
- 发布时选择目标知识库，以 source_type=wiki 走完整入库流水线（解析→清洗→分片→索引）；编辑已有页发布自动走该文档新版本（旧版分片/向量级联清理）
- 响应式：宽屏（≥900px）左树右内联内容（阅读与编辑连贯）；窄屏点树节点用 Drawer 弹出展示/编辑
- 知识库文档列表中 Wiki 文档可直达编辑页（?title= 深链）

### 3.10 知识图谱
- 三层内容：概念（is-a 本体+同义词）/ 实体（挂概念，含事件类型）/ 关系（类型化谓词+证据链回指原文）
- LLM Schema 约束抽取（候选态入库，人工确认后参与关联检索）
- 批量确认/拒绝 + 一键确认全部候选（确认关系级联确认两端实体）
- ECharts 力导向图可视化（≤300 节点 Canvas，超过自动切 WebGL）
- 健康体检：孤立实体/悬空证据/候选积压/未覆盖文档（悬空一键清理）
- 图谱洞察：枢纽实体（度中心性）/ 知识社区（模块度聚类）/ 孤立节点
- 关联检索预览：实体链接→多跳扩展→关系链展示

### 3.11 会话
- 会话列表（置顶/搜索/删除/重命名）
- 历史消息按问答交替排列，引用完整保留
- 问答反馈（点赞/点踩+备注），差评联动沉淀引导（一键补充 QA 或跳 Wiki 撰写）

### 3.12 Token 用量统计
- 纯用量口径：按厂商 × 模型 × 用途 × 日，统计输入/输出 token / 调用次数
- 厂商自动识别（DeepSeek/智谱/OpenAI/SiliconFlow/本地 local，可配置覆盖）
- 趋势图 / Top 排行 / 明细表 / CSV 导出
- QA 命中与缓存命中计为"节省量"

### 3.13 系统管理
- 管理员登录（JWT），内置账号（.env 配置）
- 运行时检索参数配置（即时生效，范围校验+审计快照）
- 清洗规则库管理（按知识库绑定，启停/优先级/试跑预览）
- 审计日志（只增，分页查询）
- 检索评测工作台（评测集→Recall@k/MRR→A/B 对比）
- 组件健康检查（MySQL/Redis/向量库/图谱/Provider 探活）

### 3.14 日志
- 控制台 + 滚动文件（logs/wl2.log，10MB×5）
- 请求日志中间件：方法/路径/状态码/耗时 + trace-id 贯穿 SSE

## 4. 非功能需求

| 维度 | 指标 |
|---|---|
| 性能 | 检索 P95 ≤500ms（不含 LLM）；首 token：远程 ≤2s / 本地 ≤5s；QA 命中 ≤200ms |
| 可用性 | 月度 ≥99.5%；降级矩阵（LLM 401→提示切本地，向量库→BM25，Rerank→跳过，Redis→内存） |
| 安全 | V1 可信内网边界；管理面 JWT；密钥 AES-GCM 加密；审计只增 |
| 可扩展 | 全组件 Provider 抽象，本地/远程双模式配置切换；向量库可插拔（Qdrant/Milvus/FAISS）；OCR 可切换（Tesseract 本地/GLM-4V 远程/auto） |
| 部署 | Docker Compose / K8s 双形态；纯内网离线部署 |

## 5. 范围外（V2）

认证与 RBAC 权限（以知识库为维度）、API 网关、开放 API（API Key scope）、多租户。详见《第二版扩展功能文档》。
