# WisdomLink2 详细设计文档（正式版 v1.0）

> 基于代码实际状态反向整理，描述接口、数据结构与核心算法。

## 1. 接口清单

浏览器 API 前缀 `/api`，OpenAPI 文档自动生成于 `/docs`。

### 1.1 知识库（kb）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/kb` | 知识库列表（含文档数/QA 数） |
| POST | `/api/kb` | 创建（同名 409） |
| PATCH | `/api/kb/{id}` | 更新描述/策略/归档 |
| DELETE | `/api/kb/{id}` | 归档（整体退出检索） |
| GET | `/api/kb/{id}/folders` | 文件夹树（含文档计数） |
| POST | `/api/kb/{id}/folders` | 新建文件夹（≤5 级） |
| DELETE | `/api/kb/folders/{id}` | 删除（文档可移动或回落根） |

### 1.2 文档（documents）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/documents` | 列表（文件夹/状态/标题筛选，分页+尺寸选择） |
| POST | `/api/documents/upload` | 上传（multipart：kb_id/folder_id/new_version/source_type/**doc_id**/file；带 doc_id 时对指定文档原地升新版本，Wiki 编辑复用此路径，旧版分片/向量级联清理） |
| GET | `/api/documents/{id}` | 详情（元数据/版本/分片视图/清洗日志） |
| PATCH | `/api/documents/{id}` | 更新元数据/上下线 |
| DELETE | `/api/documents/{id}` | 软删除（回收站 30 天） |
| POST | `/api/documents/{id}/rebuild` | 按原文重建索引 |
| GET | `/api/documents/{id}/preview` | 在线预览（md/pdf/图片直出；Office→Markdown；降级下载） |
| GET | `/api/documents/{id}/images/{n}` | 文档嵌入图片（Markdown 预览引用） |

### 1.4 会话与问答（chat）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/chat/sessions` | 会话列表（置顶优先） |
| POST | `/api/chat/sessions` | 创建（记忆检索范围） |
| GET | `/api/chat/sessions/{sid}/messages` | 历史消息（问答交替，含引用） |
| DELETE | `/api/chat/sessions/{sid}` | 删除会话及消息 |
| GET | `/api/chat/sessions/search` | 搜索会话（标题匹配） |
| POST | `/api/chat/sessions/{sid}/pin` | 置顶/取消 |
| POST | `/api/chat/stream` | SSE 流式问答（事件：meta/status/qa_hit/delta/citations/done） |
| POST | `/api/chat/feedback` | 反馈（up/down+备注） |
| GET | `/api/chat/feedback/list` | 反馈列表（差评=沉淀候选） |

**SSE 事件协议**：
```
meta:     {session_id, trace_id}
status:   {stage(检索中/生成中), entities, degraded, rerank, reranked}
qa_hit:   {qa_id, mode, score, answer, ...}   # QA 命中秒回
delta:    {text}                              # 逐 token 增量
citations:[{seq, chunk_id, doc_id, page, heading_path, snippet, score, source}]
done:     {message_id, answer_type, latency_ms, token_in/out, tokens_saved,
           rerank, reranked, degraded}
```

## 2. 数据结构

### 2.1 核心表（17 张）

| 表 | 关键字段 | 说明 |
|---|---|---|
| kb | name, tenant_id(V2预留), is_local_only, strategy_bind | 唯一权限单元 |
| folder | kb_id, parent_id, path(物化路径), depth(≤5) | 仅分类 |
| document | kb_id, folder_id, sha256, current_version, status, source_type(file/wiki) | 状态机 BR-008 |
| doc_version | document_id, version, is_current | 版本管理 |
| chunk_meta | doc_version_id, seq, role(parent/child), chunk_type(text/table/code), active, clean_hash | 分片+类型+代次标记 |
| clean_rule / clean_log | 规则链 + 逐条留痕 | BR-009 |
| qa_pair | std_question, std_answer, variants_json, enabled, hit_count, review_due_at | QA 对 |
| chat_session / message | scope_json / citations_json, answer_type, tokens_saved, degraded | 会话与消息 |
| message_feedback | message_id, value(up/down), comment | 反馈 |
| model_usage | stat_date, model_id, provider(厂商), purpose, prompt/completion_tokens, is_estimated | 计量 |
| kg_concept / kg_node / kg_edge | 概念is-a+同义词 / 实体挂概念+候选态 / 关系+evidence_chunk_id | 图谱三层 |
| audit_log | actor, action, object, detail | 只增 |
| sys_config | key, value, version | 运行时配置 |

### 2.2 向量库集合

| 集合 | 字段 | 用途 |
|---|---|---|
| chunk_{kb_id} | chunk_id, vector(dim), text, kb_id/folder_id/doc_id/doc_version_id/page/heading_path/parent_seq | 检索（payload 含标量索引） |
| qa_{kb_id} | qa_id, vector, text, weight, enabled | QA 相似命中 |

## 3. 核心算法

### 3.1 混合检索 + RRF
```
score(c) = Σ 1/(k + rank_i), k=60   # 三路排名融合
图谱回捞作为独立一路参与
并列分按 chunk_id 升序稳定排序
```

### 3.2 QA 两级命中
```
第一级：归一化精确（小写/全半角/空白合并/首尾标点去）→ Redis 字典 O(1)
第二级：向量相似 ≥0.92 且与次高分差 ≥0.02（双阈值防误命中）
多库命中 → 分数最高 → 权重 → 库序
```

### 3.3 语义分片
```
原子块保护：表格/代码不内切
句子边界：切点落在终结符（。！？.!?;）
结构块二次切分：超 1.5× 上限按行组/行中点二分
类型标签：_chunk_type(text) 按内容检测（|≥4 → table；```/def/class → code）
```

### 3.4 generation 原子发布
```
新代 chunk: active=False → 向量化写入 → UPDATE SET active=True
旧代: UPDATE SET active=False
检索只查 active=True（重建期间无检索真空）
```

### 3.5 清洗规则链
```
白名单动作: remove | normalize | mark
页眉页脚: 跨页首/尾重复 ≥3 次的短行自动识别
水印: 正则匹配替换（留痕）
脱敏: 手机号/身份证/银行卡正则 → [标签]
每条动作写 clean_log（rule_type/position/before/after）
```

### 3.6 OCR Provider（图片文字提取）
```
模式: none | local | api | auto
local: pytesseract（chi_sim+eng）→ Docker 容器内置 Tesseract
api:   LLM 视觉模型（OpenAI 兼容 /chat/completions + image_url）
       图片 base64 编码 → GLM-4V-flash → 返回提取文本（保持排版）
auto:  local 先试 → 空结果或异常自动切 api
Key 回退: WL2_OCR_API_KEY 为空时自动继承 WL2_EMB_REMOTE_API_KEY（同厂商共用）
失败降级: 占位块 [图片文件：xxx，N KB，暂未提取文字内容]（不阻塞入库）
```

### 3.7 PPT 解析（python-pptx）
```
逐页提取: slide.shapes → text_frame（标题/正文）
表格: shape.has_table → 行×列转管道分隔文本
备注: slide.notes_slide.notes_text_frame → [备注] 前缀
页码: slide 编号（1-based），heading_path 记录每页标题
```
